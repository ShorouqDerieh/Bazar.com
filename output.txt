============================================================
ANALYSIS
============================================================

1. Caching helps significantly:
   - Cache HIT  ~1 ms  (in-memory lookup only)
   - Cache MISS ~18 ms (network round-trip to catalog replica)
   - Speedup: ~15x for repeated info queries

2. Cache consistency overhead is minimal:
   - Invalidation call: ~2 ms (POST to frontend /invalidate)
   - This is small compared to the savings from caching

3. Purchase is the slowest operation (~35 ms) because it:
   - Queries the catalog to verify stock
   - Updates the catalog (triggers invalidation + peer sync)
   - Logs the order to disk

4. Post-invalidation MISS latency (~19 ms) is similar to
   cold MISS because the data must be re-fetched from the
   catalog replica over the network.
